# Business SQL & Cloud Analytics Portfolio

Repositorio de consultas analíticas estructuradas bajo el marco de **Analytics Translation**, enfocado en la resolución de problemas operativos, auditoría administrativa y extracción de valor de negocio mediante **SQL estándar** y su aplicación hacia **Google Cloud (BigQuery Studio)**.

---

## 🎯 Enfoque Metodológico: Analytics Translation
Cada consulta en este repositorio trasciende la sintaxis técnica para responder a una necesidad de gestión operativa bajo la regla de tres niveles:
* **Nivel Técnico:** Sintaxis limpia, optimización de filtros (`WHERE`, `HAVING`), subconsultas, funciones de agregación y transformaciones tabulares.
* **Nivel Negocio:** Problemas de equidad salarial, normalización de inventarios, análisis de ventas y benchmarking competitivo.
* **Nivel Traducción (ROI):** Síntesis de métricas clave para la toma de decisiones directivas sin jerga innecesaria.

---

## 📂 Estructura del Portafolio

### 1. Auditoría y Manipulación de Datos de Negocio (`/01_casos_negocio_intermedios`)
* **Auditoría de Niveles Salariales:** Uso de `LIMIT` y `OFFSET` para extraer y analizar mandos medios excluyendo la alta dirección para control presupuestal.
* **Normalización de Catálogos e Inventarios:** Funciones de cadena (`REPLACE`, `LOWER`) para estandarización de registros y calidad de reportes.
* **Benchmarking de Liderazgo:** Subconsultas con `MAX()` para identificar organizaciones líderes de mercado y calibrar metas de crecimiento.
* **Clasificación Cualitativa:** Estructuración de lógica condicional (`CASE WHEN`) para categorización de clientes y métricas de desempeño.
* **Modelado Relacional e Integridad:** Definición de llaves foráneas (`FOREIGN KEY`), restricciones de unicidad (`UNIQUE`) y combinaciones relacionales (`INNER JOIN`, `LEFT JOIN`, `UNION`).

### 2. Análisis Exploratorio y Operaciones (`/02_mode_analytics_cases`)
* **Análisis de Producción Regional:** Consultas aritméticas de aportación porcentual sobre unidades de vivienda por región geográfica.
* **Filtrado Lógico Multivariable:** Implementación de operadores lógicos complejos (`BETWEEN`, `IN`, `ILIKE`, `IS NULL`) para segmentación de registros históricos.
* **Estandarización de Nomenclatura:** Homogeneización de campos con alias explícitos (`AS`) para facilitar la ingesta en capas de visualización.

### 3. Fundamentos y Auditoría Sintáctica (`/03_sqlzoo_fundamentos` y `/00_fundamentos_sintaxis`)
* Filtros atómicos, ordenamiento multicriterio y funciones de agregación base (`COUNT`, `AVG`, `DISTINCT`).
