# Business SQL & Cloud Analytics Portfolio

Repositorio de consultas analíticas avanzadas y traducción de datos a decisiones de negocio (**Analytics Translation**), enfocado en la infraestructura de **Google Cloud (BigQuery Studio)** y optimización operativa.

---

## 🎯 Enfoque de Analytics Translation
Cada caso de estudio en este repositorio sigue la regla de traducción en tres niveles:
1. **Nivel Negocio**: Identificación del problema operativo, KPI financiero o merma (margen, retención, costos).
2. **Nivel Técnico**: Arquitectura de consulta en SQL estándar (CTEs, Window Functions, particionamiento en BigQuery).
3. **Nivel Traducción (ROI)**: Síntesis ejecutiva y hallazgos interpretados para la toma de decisiones directivas.

---

## 🛠️ Stack Tecnológico
- **Motor SQL**: Google BigQuery / PostgreSQL
- **Técnicas**: Common Table Expressions (`WITH`), Window Functions (`OVER`, `RANK`, `LEAD`, `LAG`), agregaciones complejas.
- **Entorno**: BigQuery Sandbox & GitHub Desktop.

---

## 📂 Casos y Estructura
- `/01-ecommerce-thelook/`: Análisis de retención de clientes, mermas de carrito y valor de vida (LTV).
- `/02-agro-operations/`: Modelado de costos de acarreo, rendimientos y variaciones operativas.
- `/03-advanced-techniques/`: Consultas de referencia técnica (CTEs recursivos, optimización de bytes procesados).
